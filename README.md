# Antisacadas — demostración web

Tarea interactiva en español hecha en HTML, CSS y JavaScript para **revisión del diseño** de un paradigma de antisacadas.

## Ejecutar
Abre `index.html` en Chrome o publícalo con GitHub Pages. No necesita dependencias.

## Publicar con GitHub Pages
1. Crea un repositorio público llamado `antisacadas-task`.
2. **Add file → Upload files** y sube `index.html` y `README.md`.
3. **Commit changes**.
4. Ve a **Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save**.
5. URL esperada: `https://TU-USUARIO.github.io/antisacadas-task/`.

## Límites
**NO es un eye-tracker.** Las respuestas con teclado o botones solo permiten revisar la secuencia de estímulos e instrucciones. La latencia registrada es la respuesta manual; no es la latencia sacádica. Los resultados no son válidos para inferir control inhibitorio ocular. Para investigación real se necesita eye-tracker calibrado y software sincronizado con el sensor. Los parámetros de tiempos y ensayos son preliminares y requieren validación/piloto.

## Privacidad
No se envían los datos a servidores ni se guardan online. Se descargan en CSV al elegir esa opción.
